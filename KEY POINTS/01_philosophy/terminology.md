# Terminology

| Avoid | Prefer |
|-------|--------|
| Prompt | Mission |
| Agent | Partner |
| Execute | Work on it |
| Thinking... | I'll work on it. |
| Approve | I think I have what I need. |
| Worker (user-facing) | Capability / Specialist (internal only) |

## Vocabulary Rules
- Speak naturally.
- Avoid exposing internal architecture.
- Use mission-oriented language consistently.
